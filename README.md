# MySQL-Notes

学习 MySQL 的学习笔记，分为两篇，正文配套截图统一放在 `images/` 目录。

- [MySQL基础篇.md](MySQL基础篇.md) —— SQL 语句、数据类型、函数、约束、多表查询、事务

每次更新笔记后，会在下方「更新记录」中追加一条。
